# Incident playbook

Account compromise checklist:

1. Review failed login history.
2. Check successful login location.
3. Review related service or registry access.
4. Review blocked tool or export attempts.
5. Request an investigator summary.
6. Use read-only tools for more context.
7. If needed, request session revocation.
8. Get responder/admin approval.
9. Run the action through the tool gateway.
10. Confirm follow-up events.
11. Close the incident with a resolution note.
